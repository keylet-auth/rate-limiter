# 📦 rate-limiter — Token Bucket Rate Limiter for Go

**rate-limiter** is a lightweight Go library implementing the **Token Bucket** algorithm with:

- Redis-backed token storage
- Configurable RPS, Burst, and TTL
- Clean API
- Context support (`context.Context`)
- Full unit and integration test coverage

Published as: `github.com/keylet-auth/rate-limiter`

---

## 🚀 Installation

```bash
go get github.com/keylet-auth/rate-limiter@latest
```

---

## ⚙️ Configuration

```go
type BucketConfig struct {
    RPS   float64       // tokens added per second
    Burst float64       // bucket capacity
    TTL   time.Duration // how long to keep bucket state in storage
}
```

Example:

```go
cfg := ratelimiter.BucketConfig{
    RPS:   5,
    Burst: 10,
    TTL:   time.Minute,
}
```
---

## 🏗 Usage: TokenBucket

```go
bucket := ratelimiter.NewTokenBucket(store, cfg)

allowed, err := bucket.Consume(ctx, "user:123")
if err != nil {
    // storage or network error
}

if !allowed {
    // reject (429)
}

```

## 📡 RedisTokenStore (production-ready)

```go
import (
    "context"
    "time"

    "github.com/redis/go-redis/v9"
    ratelimiter "github.com/keylet-auth/rate-limiter"
)

func main() {
    ctx := context.Background()

    rdb := redis.NewClient(&redis.Options{
        Addr: "localhost:6379",
    })

    store := ratelimiter.NewRedisTokenStore(rdb)

    bucket := ratelimiter.NewTokenBucket(store, ratelimiter.BucketConfig{
        RPS:   5,
        Burst: 10,
        TTL:   time.Minute,
    })

    allowed, err := bucket.Consume(ctx, "ip:127.0.0.1")
    if err != nil {
        panic(err)
    }

    if allowed {
        // request accepted
    } else {
        // rate limit exceeded
    }
}
```

## 🧪 Testing

Integration tests use miniredis, an in-memory Redis emulator.

Install:

```bash
go get github.com/alicebob/miniredis/v2
```

Example:

```go
mr, _ := miniredis.Run()
defer mr.Close()

rdb := redis.NewClient(&redis.Options{Addr: mr.Addr()})
store := ratelimiter.NewRedisTokenStore(rdb)
bucket := ratelimiter.NewTokenBucket(store, cfg)

allowed, _ := bucket.Consume(ctx, "key")

```

Included integration tests verify:

- state creation
- token consumption
- regeneration through elapsed time
- TTL correctness
- atomic Redis pipeline behavior
